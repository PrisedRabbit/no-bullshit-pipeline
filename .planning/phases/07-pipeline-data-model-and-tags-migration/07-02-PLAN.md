<task type="auto">
  <name>Task 1: Add zero-step early return in pipeline engine and skip transcript check for labels</name>
  <files>src-tauri/src/pipeline_engine.rs</files>
  <action>
  In `execute_pipeline_internal()`, add a zero-step guard AFTER `validate_pipeline()` and BEFORE the transcript existence check. This is critical because label pipelines should not require a transcript:

  After the line `validate_pipeline(&pipeline)?;` and before the transcript check block, insert:

  ```rust
  // PIPE-01: Zero-step pipeline = label only; skip execution, return Done immediately
  if pipeline.steps.is_empty() {
      update_pipeline_state(recording_id, pipeline_name, PipelineStatus::Done, None, None)?;
      return Ok(PipelineStatus::Done);
  }
  ```

  **Why before transcript check:** A zero-step label pipeline has no steps to execute, so it does not need a transcript. Requiring a transcript for label assignment would break the UX — users assign labels before recording is even transcribed.

  **What this does NOT change:**
  - `assign_pipeline()` is unchanged — it already sets Waiting status for any pipeline.
  - `get_pipeline_output_dir()` is unchanged — zero-step pipelines never create output dirs since no steps run.
  - PIPE-05 output isolation already works via `get_pipeline_output_dir()` returning `{data_dir}/{recording_id}/pipelines/{pipeline_name}/` — each pipeline writes to its own subdirectory. No changes needed.

  **Also add a test** in the `pipeline_engine.rs::tests` module:
  ```rust
  #[test]
  fn test_pipeline_output_dir_isolation() {
      // PIPE-05: Each pipeline gets its own output directory
      let dir_a = get_pipeline_output_dir("rec-1", "pipeline-a");
      let dir_b = get_pipeline_output_dir("rec-1", "pipeline-b");
      assert_ne!(dir_a, dir_b);
      assert!(dir_a.to_string_lossy().contains("pipelines/pipeline-a"));
      assert!(dir_b.to_string_lossy().contains("pipelines/pipeline-b"));
  }
  ```
  </action>
  <verify>Run `cargo check` from `src-tauri/` to confirm no compile errors. Verify the zero-step guard is placed before the transcript check. Run `cargo test` from `src-tauri/` to confirm existing tests pass and the new isolation test passes.</verify>
  <done>execute_pipeline_internal() returns Done immediately for zero-step pipelines without checking for transcript. PIPE-05 output directory isolation confirmed with test. No changes needed for multi-pipeline support — it already works.</done>
</task>
