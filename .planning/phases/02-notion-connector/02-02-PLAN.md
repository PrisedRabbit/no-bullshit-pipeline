The `rename_all = "lowercase"` attribute will serialize this as `"notion"`.

**2. Add Notion validation in `validate_step_config()`:**

Add a new match arm after `ConnectorType::Mcp`:
```rust
ConnectorType::Notion => {
    if step.config.get("integration_id").and_then(|v| v.as_str()).is_none() {
        return Err(format!(
            "Step '{}': Notion connector requires 'integration_id' in config",
            step.name
        ));
    }
}
```

This mirrors the Slack validation pattern. Only `integration_id` is required because the database_id and other config come from the stored integration profile.
