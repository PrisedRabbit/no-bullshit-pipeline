In `src/pipeline-builder.js`, in the `showStepEditor()` function, in the `else if (step.connector === 'notion')` branch where `configFields` is built for connected Notion profiles:

1. After the integration `<select>` dropdown, add a Re-sync Schema button row:
   ```
   <div class="step-editor-row">
     <button class="mini-action-btn resync-notion-schema-btn" style="font-size: 0.8rem;">Re-sync Schema</button>
     <span class="resync-status" style="font-size: 0.8rem; color: var(--text-secondary); margin-left: 8px;"></span>
   </div>
   ```

2. After the editor element (`editorEl`) is created and inserted into the DOM (after `stepEl.replaceWith(editorEl)`), attach a click handler for the re-sync button. The handler must be wired AFTER the editor is in the DOM. Place this code after `stepEl.replaceWith(editorEl);` and before the connector change listener, scoped inside the `step.connector === 'notion'` check:

   ```javascript
   if (step.connector === 'notion') {
     const resyncBtn = editorEl.querySelector('.resync-notion-schema-btn');
     if (resyncBtn) {
       resyncBtn.addEventListener('click', async () => {
         // Get currently selected integration_id from the dropdown
         const integrationSelect = editorEl.querySelector('[data-field="integration_id"]');
         const integrationId = integrationSelect ? integrationSelect.value : '';
         if (!integrationId) {
           const statusSpan = editorEl.querySelector('.resync-status');
           if (statusSpan) statusSpan.textContent = 'Select an integration first';
           return;
         }

         // Find the profile to get database_id and database_name
         const profiles = (typeof notionProfiles !== 'undefined') ? notionProfiles : [];
         const profile = profiles.find(p => p.id === integrationId);
         if (!profile || !profile.database_id) {
           const statusSpan = editorEl.querySelector('.resync-status');
           if (statusSpan) statusSpan.textContent = 'No database synced for this integration';
           return;
         }

         resyncBtn.disabled = true;
         resyncBtn.textContent = 'Syncing...';
         const statusSpan = editorEl.querySelector('.resync-status');
         if (statusSpan) statusSpan.textContent = '';

         try {
           const updatedProfile = await window.__TAURI__.core.invoke('sync_notion_schema', {
             integrationId: integrationId,
             databaseId: profile.database_id,
             databaseName: profile.database_name,
           });

           // Update the notionProfiles global so other UI stays current
           const idx = notionProfiles.findIndex(p => p.id === integrationId);
           if (idx >= 0) {
             notionProfiles[idx] = updatedProfile;
           }

           resyncBtn.textContent = 'Re-sync Schema';
           resyncBtn.disabled = false;
           if (statusSpan) {
             statusSpan.style.color = 'var(--text-secondary)';
             statusSpan.textContent = 'Schema synced successfully';
           }
         } catch (err) {
           resyncBtn.textContent = 'Re-sync Schema';
           resyncBtn.disabled = false;
           if (statusSpan) {
             statusSpan.style.color = '#e6453d';
             statusSpan.textContent = 'Sync failed: ' + String(err);
           }
         }
       });
     }
   }
   ```

3. The button should only appear when profiles exist (not in the "No Notion integrations connected" empty state). Since the `configFields` with the re-sync button is only built inside the `profiles.length > 0` branch, this is naturally handled.

4. Key design decisions:
   - Re-sync uses the EXISTING `sync_notion_schema` Tauri command — no new backend code needed
   - The `notionProfiles` global is updated in-place so that any subsequent pipeline builder interactions see fresh data
   - Success/error feedback shown inline next to the button via the `.resync-status` span
   - Button shows "Syncing..." while in progress, returns to "Re-sync Schema" when done
   - If no integration is selected in the dropdown, shows a helpful message instead of attempting sync
