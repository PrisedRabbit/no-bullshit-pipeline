<objective>
Implement the DOM health audit engine, status badge, and diagnostic report modal.

Purpose: Catch element regressions at startup — every time the app loads, a silent audit verifies all v2 interactive elements are present in the DOM. A persistent badge in the app bar gives instant visual feedback. When failures exist, clicking the badge shows exactly which elements are missing and how to fix them.

Output: `src/ui-health-check.js` with `runHealthAudit()`, `renderHealthBadge()`, `showHealthReport()`, `initHealthCheck()`; badge and modal HTML in `index.html`; CSS in `styles.css`; audit scheduling in `main.js`.

**AUDIT_ELEMENTS array** — comprehensive list of all always-present v2 interactive element IDs. Include every element from the research `ALWAYS_PRESENT_ELEMENTS` list:
- App bar: `record-toggle-btn`, `pipeline-chip-bar`, `status-indicator`, `timer`, `permission-warning`
- Sidebar: `settings-btn`, `sidebar-pipelines-btn`, `sidebar-templates-btn`
- Settings view: `settings-view`, `settings-tabs`, `save-settings-btn`, `settings-back-btn`

- Settings > Integrations (containers only): `connected-integrations-list`, `available-integrations-list`
- Settings > Theme: `theme-purple-btn`, `theme-blue-btn`, `theme-light-btn`
- Detail view: `detail-view`, `back-btn`, `detail-title`, `process-btn`, `detail-pipeline-select`
- Modals: `delete-modal`, `add-slack-modal`, `notion-wizard-modal`, `onboarding-overlay`

Each entry: `{ id: 'element-id', desc: 'Human-readable description' }`

**`runHealthAudit()` function:**
- Iterate AUDIT_ELEMENTS, check `document.getElementById(id) !== null` for each
- For missing elements, push `{ element: id, description: desc + ' is missing from the DOM', fix: 'Check index.html for element with id="' + id + '"' }`
- Return `{ passed: count, failed: count, issues: [] }`
- After computing result, call `renderHealthBadge(result)`
- Store result on `window._lastHealthResult` so the report can be re-opened

**`renderHealthBadge(result)` function:**
- Get `#health-badge` element
- If `result.failed === 0`: set class `health-badge health-badge-ok`, textContent `✓`, title `'UI health: all N elements verified'`, cursor default, onclick null
- If `result.failed > 0`: set class `health-badge health-badge-fail`, textContent `'⚠ ' + result.failed`, title with failure count, cursor pointer, onclick calls `showHealthReport(result.issues)`
- Set `badge.style.display = ''` to make visible

**`showHealthReport(issues)` function:**
- Get `#health-report-modal` and `#health-report-body`
- Set body innerHTML to mapped issue cards. Each card: element ID (bold), description (secondary text), fix suggestion (accent color). Use `escapeHtml()` for all dynamic text. Use inline styles consistent with existing modal patterns (var(--bg-card), var(--danger), var(--text-secondary), var(--accent)).
- Set modal `display = 'flex'`

**`initHealthCheck()` function:**
- Wire `#health-report-close-btn` click to hide `#health-report-modal` — listener attached ONCE here (not in showHealthReport)
- Wire `#health-report-rerun-btn` click to call `runHealthAudit()` and hide modal if all pass
- This function is called from main.js after init() resolves, before the audit runs

Do NOT declare any `var` globals. All state is module-local (const/let). Do NOT use ES modules (no import/export) — this is a plain script tag.

**main.js change** — Replace the last line `init().catch(e => console.error('Init failed:', e));` with:

```javascript
init().catch(e => console.error('Init failed:', e)).finally(() => {
  // Initialize health check controls (event listeners wired once)
  if (typeof initHealthCheck === 'function') initHealthCheck();

  // Schedule DOM audit after browser is idle
  const scheduleAudit = () => {
    if (typeof runHealthAudit === 'function') {
      runHealthAudit();
    }
  };
  if (typeof requestIdleCallback !== 'undefined') {
    requestIdleCallback(scheduleAudit, { timeout: 2000 });
  } else {
    setTimeout(scheduleAudit, 500);
  }
});
```

Note: The `typeof` guards are safety checks — ui-health-check.js loads after main.js, but the `.finally()` callback runs asynchronously after init() completes, by which time all scripts are loaded.
