  <action>
    **In `src-tauri/src/integrations/notion.rs`, add three Tauri commands:**

    1. **`update_notion_people_mappings`** — Tauri command accepting `integration_id: String, mappings: Vec<PeopleMapping>`:
       - Load the existing profile: `load_notion_profile(&integration_id)?`
       - Validate each mapping: every `notion_user_id` in the mappings must exist in `profile.workspace_users`. If a mapping references a user ID not in workspace_users, return error: "User ID '{id}' not found in workspace users. Re-sync the schema to refresh the user list."
       - Replace `profile.people_mappings` with the new `mappings`
       - Save the updated profile: `save_notion_profile(&profile)?`
       - Return `Ok(())` on success

    2. **`test_notion_integration`** — Tauri command accepting `integration_id: String`:
       - Retrieve the token: `get_notion_token(&integration_id)?`
       - Create a Notion client from the token
       - Call `client.users.retrieve_your_tokens_bot_user().await` to verify the token is still valid
       - If valid, return `Ok("Connected".to_string())`
       - If invalid (any error), return a descriptive error: "Notion connection failed: {error}. The API key may have been revoked."
       - Do NOT log or include the actual token in any error message

    3. **`remove_notion_integration`** — Tauri command accepting `integration_id: String`:
       - Delete the token: `delete_notion_token(&integration_id)?` — if the token doesn't exist in the credential store, log a warning but don't fail (the profile may have been partially created)
       - Delete the profile file: `delete_notion_profile(&integration_id)?` — if the file doesn't exist, that's OK (treat as success)
       - Return `Ok(())`
       - Both deletion operations should be attempted even if one fails — collect errors and return them together if both fail

    4. **Register all three commands in `lib.rs` invoke_handler.** Add to the Notion section:
       ```
       integrations::notion::update_notion_people_mappings,
       integrations::notion::test_notion_integration,
       integrations::notion::remove_notion_integration,
       ```

    5. Run `cargo check` to verify all six Notion commands compile and are registered.
  </action>

  </verify>
