The observer setup should query for the integrations tab directly, without the wrapping `settingsContainer` check.

Replace the current block (lines 887-894):
```js
const settingsContainer = document.querySelector('.settings-tabs-container');

    observer.observe(intTab, { attributes: true, attributeFilter: ['class'] });
  }
}
```

With:
```js
const intTab = document.querySelector('.settings-tab-content[data-tab="integrations"]');
if (intTab) {
  observer.observe(intTab, { attributes: true, attributeFilter: ['class'] });
}
```

This is a 3-line deletion (the `settingsContainer` query, its `if` opening brace, and one closing brace). The inner `intTab` check and `observer.observe` call remain exactly as-is. Do NOT change the MutationObserver callback (lines 880-885) — it already correctly checks for `.settings-tab-content[data-tab="integrations"]` with `.classList.contains('active')`.
