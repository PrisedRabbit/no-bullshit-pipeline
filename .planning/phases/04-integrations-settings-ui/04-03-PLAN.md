**Create `src-tauri/src/integrations/save_path.rs`:**

Follow the exact same patterns established in `notion.rs` for profile I/O. Save path profiles are stored as `save-path-{id}.json` in `~/.nbp/integrations/` (same directory as Notion profiles).

**Types:**

```rust
use serde::{Deserialize, Serialize};
use std::fs;
use std::os::unix::fs::PermissionsExt;
use uuid::Uuid;

/// A named save path integration profile.
/// Stored as `~/.nbp/integrations/save-path-{id}.json`.
#[derive(Serialize, Deserialize, Clone, Debug)]
pub struct SavePathProfile {
    pub id: String,
    pub name: String,
    pub path: String,
}
```

**CRUD commands (all `#[tauri::command]`):**

1. `add_save_path_integration(name: String, path: String) -> Result<String, String>`:
   - Validate name is non-empty, path is non-empty
   - Generate UUID via `Uuid::new_v4().to_string()`
   - Create `SavePathProfile { id, name, path }`
   - Save to `~/.nbp/integrations/save-path-{id}.json` using `crate::config::get_integrations_dir()` (same pattern as `save_notion_profile`)
   - Set file permissions to 0o600
   - Return the `id` string

2. `list_save_path_integrations() -> Result<Vec<SavePathProfile>, String>`:
   - Read `~/.nbp/integrations/` directory
   - Filter files matching `save-path-*.json`
   - Parse each as `SavePathProfile`
   - Return the vector (empty vec if dir doesn't exist)

3. `update_save_path_integration(id: String, name: String, path: String) -> Result<(), String>`:
   - Load existing profile by id (error if not found)
   - Update name and path fields
   - Save back to same file path
   - Set permissions 0o600

4. `remove_save_path_integration(id: String) -> Result<(), String>`:
   - Delete `save-path-{id}.json` from integrations dir
   - Treat "not found" as success (idempotent, same pattern as `remove_notion_integration`)

**Register in mod.rs:**

Add `pub mod save_path;` to `src-tauri/src/integrations/mod.rs` after the existing `pub mod notion;` line.

**Register in lib.rs:**

Add all 4 commands to the `invoke_handler!` macro in `src-tauri/src/lib.rs`, after the Notion commands section:

```rust
// Save path integrations
integrations::save_path::add_save_path_integration,
integrations::save_path::list_save_path_integrations,
integrations::save_path::update_save_path_integration,
integrations::save_path::remove_save_path_integration,
```

**Note:** The `uuid` crate is already a dependency (used elsewhere in the codebase for recording IDs). Verify with `grep uuid src-tauri/Cargo.toml`. If not present, add `uuid = { version = "1", features = ["v4"] }` to Cargo.toml dependencies.
