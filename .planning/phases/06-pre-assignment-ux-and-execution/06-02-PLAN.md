**config.rs:** Add two new fields to the `AppSettings` struct, after the `integrations` field:

```rust
/// Default pipeline to auto-assign to new recordings (set in Settings > Audio)
#[serde(default)]

/// Last pipeline used — highlighted in chip bar on next launch
```

Update the `Default` impl for `AppSettings` to include these fields:
```rust

last_used_pipeline: None,
```

Both use `#[serde(default)]` so existing `settings.json` files without these fields deserialize correctly (Research Pitfall 5).

**Detail view pipeline assignment (ASGN-04):**

**index.html:** Inside the `#detail-view` section, inside `.detail-header-card` (after the `<input id="detail-title">` element), add:

```html
<div id="detail-pipeline-assignment" class="detail-pipeline-assignment" style="display: none;">

  <select id="detail-pipeline-select" class="settings-select compact-select">
    <option value="">None</option>
  </select>
</div>
```

**styles.css:** Add CSS for detail pipeline assignment:

`.detail-pipeline-assignment` — `display: flex`, `align-items: center`, `gap: 8px`, `margin-top: 8px`.

`.detail-pipeline-assignment label` — `font-size: 0.75rem`, `color: var(--text-secondary)`, `white-space: nowrap`.

`.compact-select` — `font-size: 0.8rem`, `padding: 3px 8px`, `border-radius: 6px`, `max-width: 200px`.

**main.js:** In `showDetailView()`, after the content grid visibility is set and before the transcript loading section:

1. Get `#detail-pipeline-assignment` and `#detail-pipeline-select` elements.
2. If not recording and not processing, show the assignment section (`style.display = 'flex'`).
3. Populate the select with pipelines from `allPipelineDefs` (same pattern as `populateDefaultPipelineSelect`).
4. Load current pipeline assignment: call `await invoke('get_all_pipeline_states', { recordingId: id })`. If a state exists, set the select value to that pipeline name. If multiple states exist, use the first one.
5. On `change` event for the select: if value is not empty, call `await invoke('assign_pipeline', { recordingId: id, pipelineName: select.value })`. If value is empty, no action (cannot unassign currently — that is out of scope).
6. If recording or processing, hide the assignment section (`style.display = 'none'`).

**Important:** Remove and re-add the change listener each time `showDetailView` is called to avoid stacking listeners. Use a module-level reference: `let detailPipelineHandler = null;` and remove old handler before adding new one.
