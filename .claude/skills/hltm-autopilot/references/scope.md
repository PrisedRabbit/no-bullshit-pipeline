# Scope Control

## Rules

1. **ONLY implement what explicitly requested** in `input/brief.md`
2. **NEVER** invent features or add "nice-to-have" items
3. **NEVER** defer user's tasks to "Future Enhancements"
4. Stories/epics **MUST map 1:1** to original request

## If Must-Have Items Missing

Add clarifying questions to `input/questions.md` (Solutioning phase only).

## Brownfield Context

If Brownfield, respect existing architecture in `project_knowledge` or PRD.
