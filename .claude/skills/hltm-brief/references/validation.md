# Enhanced Brief Format

## Target Structure

```markdown
# Brief

## App
**Name:** [name]
**One-liner:** [what it does]

## Problem
[pain point + why important]

## Users
**Who:** [target audience]
**Context:** [mobile/desktop, when, how often]

## MVP Features
1. [feature 1]
2. [feature 2]
3. [feature 3]

## Main Flow
[User → Action → Result]

## Data
- **User:** [what to store]
- **[Entity]:** [what to store]

## Style
[Minimal / Bold / Corporate / Playful]
```

## Required Sections

All sections above must be filled after enhancement.
