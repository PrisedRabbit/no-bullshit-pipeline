## Getting Started

### Prerequisites

```bash
# macOS 13.0+ required
# Install Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Install Bun
curl -fsSL https://bun.sh/install | bash
```

### Run Development

```bash
# Clone and enter project
cd nbp

# Install dependencies
bun install

# Start development mode
bun tauri dev
```

### Build Release

```bash
# Build DMG
./build.sh

# Output: builds/nbp_v0.3.0.dmg
```
